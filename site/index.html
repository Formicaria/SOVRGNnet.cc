How it works

Your node is the centre

SOVRGNnet installs onto one machine you control. That node speaks Matrix for messaging and IPFS for files, serves the interface to your users and their devices, and federates outward on your terms.

Traffic terminates on your node. Nothing routes through Formicaria.

Install

One command. Your infrastructure.

Point it at a machine you control — a spare laptop, a home server, a Raspberry Pi — and ./install.sh brings up Matrix, IPFS, the database and the web interface together. It generates every password and asks one real question: house-only, or reachable by friends. 

git clone https://github.com/Formicaria/SOVRGNnet.cc.git sovrgnnet
cd sovrgnnet
./install.sh
Installation docs GitHub

No domain, no Cloudflare account, no prior Docker knowledge. Re-running it later keeps your existing settings.

operator@node — sovrgnnet 
$ ./install.sh✓ Docker is ready✓ Settings saved to .env (passwords generated for you)✓ Homeserver configured✓ Building and starting✓ The app is runningSOVRGNnet is live.
